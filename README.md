# Quizzler App 🎯

## 📌 Overview
Quizzler is a Python-based quiz application built with **Tkinter** for the GUI.  
It fetches trivia questions in real-time from the [Open Trivia DB API](https://opentdb.com/api.php), allowing users to test their knowledge interactively.  

This project demonstrates how to combine **API requests**, **object-oriented programming**, and a **graphical user interface** in Python.

---

## 🚀 Features
- Fetches quiz questions dynamically using Open Trivia DB.
- User-friendly GUI built with Tkinter.
- True/False buttons for answering questions.
- Score tracking during the quiz.
- Instant feedback after each answer.
- Clean separation of logic (`quiz_brain.py`), data (`data.py`), and UI (`ui.py`).
